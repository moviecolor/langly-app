What's in it

Vocabulary Builder (the core)

  • On-device translation — words and phrases translated instantly, no internet needed.
  • Users build their own custom blocks — up to 10 blocks of 15 words each (150 words total) — so students create lists from their own lessons and daily life. It comes preloaded with over 150 words in Block Categories.
  • Gamified — each block feeds the Match Madness style word game (like Duolingo but without the time limits — match pairs before time runs out) with streaks and reminders to work on your progress.
  • The same custom blocks run in Audio Mode for drilling your speaking (see below) — build once, practice two ways.

Offline + private

  • Everything runs on-device — works fully without internet.

Audio Mode

  • Hands-free repetition audio loop: English → Portuguese → repeat
  • You set the number of repetitions and the gap between each word/phrase
  • Native pronunciation via text-to-speech, in every language
  • Perfect for drilling between classes — in the car, on a walk, doing dishes — the words sink in by repetition (practice makes permanent).

Where I especially need your input

  • The entire Portuguese side of the app — titles, instructions, headings — was translated using AI, so I really want a native teacher's eyes on it to make sure it sounds natural and correct, not robotic.
  • When users add their own custom words, translation uses Google Translate when online and an internal dictionary when offline — so if you or your students spot any awkward or incorrect translations in real use, that's exactly the feedback I need.
